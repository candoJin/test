# 🎨 웹사이트 빌더 - 실시간 미리보기

블록 코딩처럼 쉽게 웹사이트를 만들 수 있는 비주얼 웹사이트 빌더입니다!

## ✨ 주요 기능

### 🎯 드래그 앤 드롭
- 왼쪽 패널에서 원하는 컴포넌트를 드래그하여 캔버스에 놓기만 하면 됩니다
- 코딩 지식 없이도 누구나 쉽게 웹사이트를 만들 수 있습니다

### 👁️ 실시간 미리보기
- 오른쪽 패널에서 실시간으로 결과를 확인할 수 있습니다
- 데스크톱, 태블릿, 모바일 화면 크기로 미리보기 가능
- 모든 변경사항이 즉시 반영됩니다

### 🎨 다양한 컴포넌트

#### 레이아웃
- **컨테이너**: 요소를 그룹화하는 박스
- **섹션**: 독립적인 페이지 영역
- **컬럼**: 2단 레이아웃

#### 텍스트
- **제목**: 큰 제목 텍스트
- **본문**: 일반 텍스트 단락

#### 미디어
- **이미지**: 사진 및 그림 삽입
- **비디오**: 동영상 삽입

#### UI 요소
- **버튼**: 클릭 가능한 버튼
- **폼**: 입력 양식
- **카드**: 정보를 담는 카드 컴포넌트
- **내비게이션바**: 상단 메뉴
- **푸터**: 하단 정보

### ⚙️ 속성 편집
- 각 요소를 클릭하여 속성을 편집할 수 있습니다
- 텍스트, 색상, 크기, 여백 등을 쉽게 변경
- 실시간으로 변경사항 확인 가능

### 💾 저장 및 내보내기
- **저장**: 브라우저에 프로젝트 저장 (다음에 이어서 작업 가능)
- **코드 내보내기**: 완성된 웹사이트를 HTML 파일로 다운로드
- **초기화**: 모든 요소를 삭제하고 새로 시작

## 🚀 사용 방법

1. **브라우저에서 index.html 파일을 엽니다**

2. **컴포넌트 추가**
   - 왼쪽 패널에서 원하는 컴포넌트를 선택
   - 마우스로 드래그하여 중앙 캔버스에 드롭

3. **내용 편집**
   - 텍스트는 직접 클릭하여 수정 가능
   - ✏️ 버튼을 클릭하여 상세 속성 편집

4. **실시간 확인**
   - 오른쪽 미리보기 패널에서 실시간으로 결과 확인
   - 화면 크기 버튼으로 반응형 확인

5. **저장 및 내보내기**
   - 💾 저장: 작업 내용 저장
   - 💾 코드 내보내기: HTML 파일로 다운로드

## 🎯 팁

- 컴포넌트는 여러 개 추가할 수 있습니다
- 드래그 순서대로 위에서 아래로 배치됩니다
- 각 요소 위에 마우스를 올리면 편집/삭제 버튼이 나타납니다
- 텍스트는 직접 클릭하여 바로 수정할 수 있습니다
- 이미지 URL을 변경하여 원하는 이미지를 사용할 수 있습니다
